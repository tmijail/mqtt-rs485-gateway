Device prefix (location)

Location levels that the gateway puts before each device name in the Sparkplug device ID, with ":" between them. Example: the levels acme, berlin, packaging and line3 give the device ID acme:berlin:packaging:line3:meter1. Write the location one time here, not in each device. Keep the list empty if the device names are the full device IDs.
