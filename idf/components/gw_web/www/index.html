Restart and reset

The gateway is in safe mode now. Restart ends it.

Safe mode stops the polling and MQTT for 60 min, or until the next restart. The configuration stays.

Erases the configuration, the secrets, the web certificate and the web password. The gateway then restarts in commissioning mode, with the access point on.
